# theme_pegasoft_preview

Maqueta estática del tema `theme_pegasoft` para el sitio web de PegaSoft SAS (Odoo 19).
Es una aproximación visual, no el sitio real de Odoo.

- `index.html`: versión oscura
- `index-claro.html`: versión clara

Se publica con GitHub Pages (Settings > Pages > rama `main`, carpeta raíz).
